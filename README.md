# 📝 Sistema de Cadastro

Sistema desenvolvido em **Java** com o objetivo de aplicar conceitos de **Programação Orientada a Objetos (POO)**, estruturas de dados e manipulação de informações por meio de operações de cadastro, consulta, atualização e remoção de registros.

Este projeto foi desenvolvido como atividade acadêmica, com foco na prática dos principais conceitos de desenvolvimento de software utilizando Java.

---

## 🚀 Funcionalidades

* ✅ Cadastro de registros
* ✅ Listagem de dados cadastrados
* ✅ Busca de informações
* ✅ Atualização de registros
* ✅ Remoção de registros
* ✅ Interface simples e intuitiva
* ✅ Validação básica de dados

> As funcionalidades disponíveis podem variar conforme a evolução do projeto.

## ▶️ Como Executar

### Pré-requisitos

* Java JDK 17 ou superior
* Uma IDE Java (IntelliJ IDEA, Eclipse ou NetBeans)

### Clone o repositório

```bash
git clone https://github.com/vithoriaCabreira/SistemaCadastro.git
```

### Acesse a pasta

```bash
cd SistemaCadastro
```

### Compile o projeto

```bash
javac *.java
```

### Execute

```bash
java Main
```

Caso utilize uma IDE, basta importar o projeto e executar a classe principal.
